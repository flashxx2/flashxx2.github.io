# flashxx2.github.io

Статические страницы для ссылок из приложения «Листок». Своего сервера у приложения нет.

- `.well-known/apple-app-site-association` — заявка Apple: по ней iOS открывает ссылки
  `/listok/task/…` в приложении, а не в браузере. Лежит в корне домена, иначе Apple её не найдёт.
- `.nojekyll` — обязателен: иначе GitHub Pages прогоняет сайт через Jekyll, а тот выбрасывает
  папки, начинающиеся с точки, вместе с заявкой.
- `listok/task/` — страница для того, кому прислали задачу, а приложения у него нет.
- `listok/wishlist/` — то же для списка желаний.

Содержимое задачи и списка едет **во фрагменте** адреса, после `#`. Фрагмент браузер на сервер
не отправляет, поэтому в журналы хостинга он не попадает.

Исходник страниц — папка `Web/` в репозитории приложения.
